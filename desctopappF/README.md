# Factory Desktop Warehouse

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start app:

```bash
npm start
```

## API path

App uses:

`https://sergey1337.pro-web24.ru/api/desktop`

## Required backend upload

Upload folder:

`W:\Учебное для подготовки\Mobil\.venv\api\desktop`

to server:

`/www/sergey1337.pro-web24.ru/api/desktop`
